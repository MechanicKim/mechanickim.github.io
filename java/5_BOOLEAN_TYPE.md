# 논리 타입

참(`true`)과 거짓(`false`) 중 하나의 값을 저장하는 타입. 주로 조건문(if)이나 반복문(for, while)의 실행 흐름을 제어하는 데 사용

### 1. boolean 타입의 특징

- **메모리 크기**: 1 byte (8 bits)
- **저장 값**: `true`, `false` (소문자만 가능)
- **용도**: 논리 연산의 결과나 상태값을 저장하여 프로그램의 흐름을 결정

```java
boolean stop = true;
boolean state = false;

if (stop) {
	System.out.println("중지합니다.");
} else {
	System.out.println("시작합니다.");
}
```

### 2. 관계 연산의 결과

관계 연산자(`>`, `<`, `==`, `!=` 등)의 결과는 항상 boolean 타입으로 반환한다.

```java
int x = 10;
boolean result1 = (x == 20); // false
boolean result2 = (x != 20); // true
boolean result3 = (x > 5);   // true
```

### 3. 논리 타입 사용 시 주의사항

- **타입 변환 불가**: 다른 타입과 상호 변환되지 않는다. `0`은 `false`, `1`은 `true`로 간주하는 방식이 자바에서는 통용되지 않으므로 주의한다.
- **초기화**: 클래스의 필드로 선언된 `boolean`의 기본값(default)은 `false`다. 하지만 메소드 안의 지역 변수로 선언할 때는 반드시 초기화를 해주어야 한다.

### 4. 논리 연산자 흐름도

논리 연산자(`&&`, `||`, `!`)와 함께 쓰여 복합적인 조건을 판단

- **AND (`&&`)**: 둘 다 참일 때만 참
- **OR (`||`)**: 둘 중 하나만 참이어도 참
- **NOT (`!`)**: 참을 거짓으로, 거짓을 참으로 반전
