# 산술 연산자

### 1. 산술 연산자의 종류

| **연산자** | **의미**   | **예시 (10, 3)** | **결과**                           |
| ---------- | ---------- | ---------------- | ---------------------------------- |
| `+`        | 더하기     | `10 + 3`         | `13`                               |
| `-`        | 빼기       | `10 - 3`         | `7`                                |
| `*`        | 곱하기     | `10 * 3`         | `30`                               |
| `/`        | 나누기(몫) | `10 / 3`         | **`3`** (정수 연산 시 소수점 버림) |
| `%`        | 나머지     | `10 % 3`         | `1`                                |

### 2. 산술 연산 시 타입 변환 규칙 (Promotion)

산술 연산을 수행 시 컴파일러가 자동으로 타입을 맞추는 규칙이 있다. 이를 모르면 예상치 못한 결과를 얻게 된다.

#### 정수 타입 연산

- `byte`, `short`, `char` 타입은 연산 시 **무조건 `int` 타입으로 변환**된 후 계산된다.
- `int`보다 큰 `long` 타입이 피연산자에 섞여 있으면, 결과는 `long` 타입이 된다.

#### 정수와 실수 연산

- 정수 타입과 실수 타입(`float`, `double`)을 연산하면 정수가 실수로 변환되어 계산된다. 결과는 더 범위가 넓은 실수 타입이 된다.

### 3. 디테일 분석: 정수 나눗셈의 함정

```java
int a = 10;
int b = 4;
double result = a / b;
System.out.println(result); // 결과: 2.0 (2.5가 아님!)
```

`int / int`는 결과도 `int`여야 한다. 따라서 `10 / 4`의 결과인 `2.5`에서 소수점을 버린 `2`가 먼저 생성되고, 이 값이 `double` 변수에 저장되면서 `2.0`이 되는 것이다.

이를 해결하려면 피연산자 중 하나를 실수 타입으로 형변환(Casting)해야 한다.

```java
double result = (double) a / b; // 10.0 / 4 => 2.5
```

### 4. 나머지 연산자 (`%`)

나머지 연산자는 주로 다음과 같은 경우에 활용한다.

- **홀수/짝수 판별**: `n % 2 == 0`이면 짝수
- **배수 판별**: `n % 3 == 0`이면 3의 배수
- **범위 제한**: 어떤 수를 N으로 나눈 나머지는 항상 `0 ~ N-1` 사이의 값을 가짐

### 5. 런타임 에러 주의: DivisionByZero

정수 연산에서 0으로 나누거나(`10 / 0`), 0으로 나머지를 구하려고 하면(`10 % 0`) 프로그램이 강제 종료되는 예외가 발생한다.

- **Error**: `java.lang.ArithmeticException: / by zero`

> 참고: 실수 연산인 10 / 0.0은 에러가 나지 않고 Infinity가 된다.

### 6. 요약 및 체크포인트

- `byte`, `short` 연산 결과는 `int`다.
- 정수 나눗셈(`/`)은 소수점을 버린 '몫'만 취한다.
- 정확한 소수점 결과를 얻으려면 최소 하나는 `double`로 캐스팅해야 한다.
