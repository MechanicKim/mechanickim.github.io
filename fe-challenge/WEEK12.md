### 25.12.9 - 이벤트 버블링

버블링은 이벤트 전파 방식 중 하나로, 특정 요소에서 발생한 이벤트가 **상위 요소로 계속 전파**되어 올라가는 것이다.

#### 이벤트 전파 3단계

1. 캡처링
   - **최상위 요소**에서 **하위 요소**로 내려가며 이벤트를 탐색
   - 목표에 도달하기 전에 가로챌 수 있음
2. 타겟
   - **실제 발생한 요소**에 도달
   - 이벤트 핸들러 실행 주요 시점
3. 버블링
   - 타겟 요소에서 **상위 요소**로 다시 올라가는 단계
   - 대부분의 이벤트 핸들러가 이 단계에서 실행

#### 버블링 작동 방식

```html
<body onclick="alert('body')">
  <div onclick="alert('div')">
    <button onclick="alert('button')">클릭!</button>
  </div>
</body>
```

1. `button`을 클릭하면 `alert('button')` 실행
2. `button`의 부모인 `div`에 전파
3. `div`의 이벤트 핸들러 `alert('div')` 실행
4. `div`의 부모인 `body`에 전파
5. `body`의 이벤트 핸들러 `alert('body')` 실행
6. 최상위 요소까지(`document`, `window`)전파된 후 종료

`button` 클릭으로 총 3개의 `alert`이 실행된다.

#### 버블링 활용: 이벤트 위임 (Event Delegation)

100개의 리스트 항목(`li`)이 있다고 할 때, 각각 이벤트 핸들러를 추가하면 메모리를 낭비하고 성능이 저하될 수 있다. 이를 개선하기 위해 이벤트 위임을 사용한다.

- 각 항목에 이벤트 핸들러를 추가하는 대신, 공통 부모 요소(`ul`)에만 하나의 이벤트 핸들러를 추가
- 각 항목에서 이벤트가 발생하면 버블링을 통해 `ul`에 이벤트가 전파되고, `ul`의 이벤트 핸들러가 이를 받아서 처리
- 핸들러 내부에서는 `event.target`으로 실제 클릭된 요소의 객체를 얻어 필요한 작업 실행

#### 버블링 막기: 이벤트 전파 중단

특정 요소까지만 이벤트를 처리하고, 상위 요소에 전파를 막기 위해 사용한다.

- `event.stopPropagation()`: 상위 요소에 전파 막기
- `event.stopImmediatePropagation()`: 현재 요소에 동일한 타입의 이벤트 핸들러가 여러 개 추가된 경우, 나머지 핸들러들의 실행과 상위 요소에 전파를 막기

### 25.12.10 - 이벤트 리스너와 핸들러

이벤트 버블링을 정리하면서 이벤트 리스너와 핸들러 중 무엇이라 해야하는지 헷갈려 정리해본다.

| **구분**        | **이벤트 리스너 (Event Listener)**                                                  | **이벤트 핸들러 (Event Handler)**                                   |
| --------------- | ----------------------------------------------------------------------------------- | ------------------------------------------------------------------- |
| **정의**        | 특정 **이벤트(Event)**가 **발생하는지 감지하고 대기**하는 메커니즘 또는 객체입니다. | 이벤트가 감지되었을 때 **실제로 실행되는 자바스크립트 함수**입니다. |
| **역할**        | 요소에 **이벤트를 등록**하는 역할(청취자).                                          | 이벤트 발생 시 **실행할 행동을 정의**하는 역할(처리 로직).          |
| **주요 메소드** | `addEventListener()` 메소드 (가장 일반적)                                           | `addEventListener()` 메소드의 **두 번째 인자(콜백 함수)**           |
